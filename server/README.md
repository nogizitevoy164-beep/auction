# Серверная основа

На первом серверном этапе используется один игровой сервер (`server_id = 1`). SQL-схема описывает постоянные данные, которые не должны доверяться клиентскому Godot-приложению.

Порядок будущей реализации:

1. REST: авторизация, профиль, инвентарь, замок и настройки.
2. WebSocket: комнаты аукциона, ставки, таймеры и серверные новости.
3. Транзакции монет и блокировка экземпляров предметов.
4. Админские операции с описаниями предметов, шансами, башнями и рецептами.

Клиент никогда не изменяет баланс, владельца предмета или результат аукциона напрямую.
